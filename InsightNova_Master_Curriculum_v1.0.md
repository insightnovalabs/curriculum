# Master Data Science Curriculum

Version 1.0 \| 25 November 2026

Learn • Practice • Build

## Purpose

Accessible learning from absolute beginner to advanced professional and
research-level knowledge in data science, analytics, machine learning
and AI. This is an educational curriculum, not an accredited
qualification or a guarantee of expertise.

## Inventory and classification

139 modules across 10 phases: 60 core, 34 professional and 45
specialization. The 16 industry pathways are separate. Original module
IDs are preserved. Phase 10 is a placeholder; project content remains
empty.

Core modules are mandatory for the general data science pathway;
professional and specialization modules are optional. Categories are
distinct from beginner, intermediate and expert learning levels. The
actual learning sequence is not yet approved.
